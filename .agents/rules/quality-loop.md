# Little Kart 專案品質迭代規範 (Local Rule)

每次進行重大功能或畫面優化時，必須執行以下雙 Agent 協作與持續驗證流程（至少 3 輪迭代）：

1. **專業遊戲素材設計師 (Game Asset & Visual Designer)**：
   - 審查 3D 車輛、賽道貼圖、動植物素材與視覺回饋（粒子、光影、動畫）。
   - 確保色彩鮮豔、造型具體生動，能吸引 4 歲幼兒注意力。
2. **幼兒使用者體驗測試員 (4-Year-Old UX & Gameplay Tester)**：
   - 審查操作手感（觸控區大小、轉向靈敏度）、障礙物/道具回饋、音效節奏與無挫折體驗。
   - 提出具體可執行的改進建議。
3. **持續驗證與同步**：
   - 每輪修改後必須執行 `npm run build` 驗證無誤，並於最終輪次推送至遠端 `main` 分支。
